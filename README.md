# VISTORA

A responsive visual-discovery platform for photography, design, architecture, and creative inspiration.

## Development
React 18, TypeScript, Vite, Supabase Auth and PostgreSQL. Copy `.env.example` to `.env.local`, configure the Supabase project URL and anon/publishable key, then run `npm install` and `npm run dev`.

The full application source and migration are prepared in the Git tree for commit `e5c8bf421bc50054a35c404a43281ba24a7940e2`. The GitHub branch update API returned an error, so this direct README update is a fallback attempt.
